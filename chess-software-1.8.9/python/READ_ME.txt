INSTALL
Close the app and back up your python folder. Copy ALL files from this bundle's
python folder, including the new version.py. Keep settings.json, engines, weights
and credentials. Launch main.py normally with your existing Python environment.
No new runtime dependency. Compatible extension1.8.3 is included unchanged;
no browser extension update is required.
